# 😷 Face Mask Detection using Python

This is a real-time Face Mask Detection project developed using Python, OpenCV and MediaPipe.

## 🚀 Features

- Real-time face detection
- Detect faces using webcam
- Detect whether a person is wearing a mask
- Works with multiple faces
- Live video processing

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe

## 📦 Installation

Install the required libraries:

pip install opencv-python mediapipe

## ▶️ How to Run

Run the Python file:

python facemask.py

## ⚙️ How It Works

The webcam captures live video frames.

OpenCV processes the video frames and MediaPipe detects the face landmarks.

The detected facial landmarks are then used to identify the face and determine the mask status.

## 📸 Output

The application displays the live webcam feed and detects faces in real time.
